# PayProof Logo Guide

## Logo Concept

The PayProof logo combines three key elements that represent our core values:

1. **Shield** - Security and trust in payment verification
2. **Receipt/Document lines** - Proof of payment and documentation
3. **Checkmark** - Verification and confirmation
4. **Stellar star element** - Connection to the Stellar ecosystem

## Design Principles

- **Modern SaaS/Fintech Style** - Professional, clean, and trustworthy
- **Flat Design** - No gradients or 3D effects for versatility
- **Vector-based** - Scalable for all applications
- **High Contrast** - Works in both light and dark modes
- **Simple & Memorable** - Easy to recognize and reproduce

## Color Palette

- **Primary Green**: #22c55e - Trust, verification, success
- **Dark Navy**: #0f172a - Professionalism, security
- **White**: #ffffff - Clarity, transparency
- **Light Gray**: #e5e7eb - Neutral backgrounds

## Logo Variations

### 1. Main Logo (`logo-main.svg` / `logo-main-dark.svg`)
- **Size**: 200×60px
- **Use case**: Website headers, presentations, marketing materials
- **Features**: Full logo with icon, text, and tagline
- **Variants**: Light and dark mode versions

### 2. Icon Only (`logo-icon.svg`)
- **Size**: 40×40px
- **Use case**: Favicons, app icons, social media profile pictures
- **Features**: Shield with verification elements only
- **Universal**: Works in all contexts

### 3. GitHub Avatar (`logo-github.svg`)
- **Size**: 64×64px
- **Use case**: GitHub organization avatar, square social media profiles
- **Features**: Icon with subtle background circle for visibility
- **Optimized**: Perfect for GitHub's avatar requirements

### 4. Navbar Version (`logo-navbar.svg`)
- **Size**: 32×32px
- **Use case**: Website navigation, compact spaces
- **Features**: Optimized icon for small sizes
- **Clean**: Minimal design for UI integration

### 5. Wordmark (`logo-wordmark.svg` / `logo-wordmark-dark.svg`)
- **Size**: 160×40px
- **Use case**: Horizontal layouts, email signatures, business cards
- **Features**: Compact icon with text
- **Variants**: Light and dark mode versions

## Usage Guidelines

### ✅ DO
- Use the provided SVG files for best quality
- Maintain the aspect ratio when scaling
- Use appropriate color versions for light/dark backgrounds
- Ensure sufficient white space around the logo
- Use the GitHub version specifically for GitHub avatars

### ❌ DON'T
- Don't modify the colors except for single-color applications
- Don't add effects, shadows, or gradients
- Don't distort or stretch the logo
- Don't place on low-contrast backgrounds
- Don't use a different font for the text

## Technical Specifications

- **Format**: SVG (Scalable Vector Graphics)
- **Font**: Inter (fallback to system fonts)
- **Primary Color**: #22c55e (CSS: `text-green-500`)
- **Stroke Width**: 2-3px for checkmarks
- **Opacity**: 0.6-0.9 for layered elements

## Brand Personality

The PayProof logo conveys:
- **Professional Infrastructure** - Not a consumer app or crypto token
- **Developer-Focused** - Clean, technical aesthetic
- **Trustworthy** - Shield symbolism and solid construction
- **Open Source** - Transparent and community-oriented
- **Stellar Ecosystem** - Subtle star element shows blockchain connection

## Inspiration

The design draws inspiration from successful fintech and developer tool brands:
- **Stripe** - Clean, professional, trustworthy
- **Linear** - Modern, minimal, developer-focused  
- **Vercel** - Simple geometry, high contrast
- **Coinbase** - Secure, established, professional

This logo positions PayProof as serious infrastructure software that developers and businesses can trust for their payment verification needs.
